# .INI Config 사용하기

STM32에 내부 메모리를 RamDisk로 인식해 설정 파일로 활용하는 방법 정리

## 0. 설정 확인을 위한 샘플 프로그램 구성

- ini 파일을 통해 설정하는 방법을 알기 위함
- 샘플 프로그램은 섹션과 변수를 구성하여 읽는 구조임
- 변수 활용을 위해 LED 깜빡이는 속도를 변경할 수 있게 함
- INI 파일 활용을 위해 섹션과 변수를 활용할 수 있게 구성
- 예제는 DMX 수신을 위한 채널 구성 방법을 설정하는 프로그램
- DMX 수신 부분은 이 프로그램에 포함하지 않음
- 장치가 사용할 DMX 채널 번호와 몇 개 채널 사용할지 정하는 프로그램
- CONFIG.INI 파일에 2가지 섹션 구성
- [DEVICE] 섹션에는 DMX 채널 번호, 몇 개 채널을 사용할지, LED 깜빡이는 간격 세팅
- [CH1] 섹션은 채널 1에 대한 변수 설정, 여기서는 Min, Max를 설정하게 했음
- [CH16] 까지 사용 가능, 최대 채널 수는 CH_COUNT에서 변경 가능
